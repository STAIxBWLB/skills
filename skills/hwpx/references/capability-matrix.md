# hwp-cli 렌더/변환 능력·한계 매트릭스

스킬이 위임하는 hwp-cli의 렌더링·변환 능력 요약. 사용자에게 결과 기대치를 정확히 전달하기 위한 참조표.

**SSOT**: `dev/hwp-cli/docs/design/12-feature-gaps.md`(갭 카탈로그 GA~GM). 이 표는 그 요약본이며 상세·근거는 SSOT를 본다. **hwp-cli v0.8.6 기준으로 재확인**(2026-08-19).

**편집 능력(`hwp edit` 플래그별 지원 범위)은 이 표에 없다** — upstream 스킬(`hwp skill export`)과 `hwp edit --help`가 정본이다. 이 표는 렌더·변환 결과물의 기대치만 다룬다.

범례: **✓** 렌더/추출됨 · **~** 근사(정품과 다름) · **✗** 미지원/드롭/블랭크

### v0.8.6 지오메트리 변경 (중요)

v0.8.6은 세 가지 텍스트 메트릭 규칙을 정품 기준으로 정정했다 — 자간이 글리프별 advance에 적용되고, `글꼴에 어울리는 빈칸` 비트가 고정 반각 공백을 의미하며, `useKerning` off가 커닝을 끈다. 결과적으로 **같은 문서라도 줄 폭·줄바꿈 위치·쪽 나눔이 v0.8.5 이전과 달라진다**(정품 대비 raster 거리는 `bad_pixel_pct` 0.01792 → 0.00569로 개선). 표 셀 안에서 뭉개지던 공백도 살아남는다(`제조업기반취약` → `제조업 기반 취약`).

실무상: **v0.8.6 이전에 측정한 쪽수·레이아웃 기대치는 재측정 대상**이다. `./hwpx guard`로 레퍼런스 대비 드리프트를 재확인한다. 이때 레퍼런스도 같은 버전으로 다시 렌더해야 의미가 있다.

## 변환 타깃 (convert --to)

| 타깃 | 상태 | 비고 |
|------|------|------|
| `hwpx` `hwp` | ✓ | hwp5→hwp5 무손실 왕복(바이트 동일) |
| `pdf` | ✓ | 텍스트 선택가능(권장: `to-pdf`) |
| `md` `html` | ✓ | 링크·이미지·각주 마커·병합셀·중첩 블록·리스트 모두 보존(GH-1~6 해소). 병합/중첩이 있으면 HTML 표로 폴백 |
| `json` | ✓ | 전체 IR. `--embed-bin`으로 이미지까지 자족적 |
| `odt` | ~ | 페이지 레이아웃(여백·다단·머리말 위치) 미재현(GH-7) |
| `docx` | ✓ / ~ | 출력 전용(GJ-1). 수식은 스크립트 텍스트로 대체, 페이지 레이아웃 재현 없음. **읽기는 미지원** |
| `txt` `csv` | ✓ | 텍스트 추출 |
| `hml`(HWPML), HWP 3.x, RTF | ✗ | (GJ-2~4) |

## 열기 거부

암호화·배포용(DRM)·서명 HWP5는 **열기 거부**(GA-1~4). 배포용 문서는 한컴오피스에서 일반 저장 후 사용.
